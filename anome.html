desktop browser — pyqt5 + qtwebengine

A Chromium browser
you can actually read.

Cysra Anome is a PyQt5 desktop browser with tabbed and private browsing, a request-layer ad blocker, a fuzzy command palette, and a side panel of small built-in apps. Open source, MIT licensed, and built to be read and extended rather than reverse-engineered.

What it does

the parts you'll actually touch

browsing

Chromium underneath

Runs on QWebEngineView with tabbed browsing, private tabs, download management, and view-source support — a real rendering engine, not a wrapper around someone else's shell.

ad blocker

Blocks at the request layer

A QWebEngineUrlRequestInterceptor filters known ad and tracker domains plus common ad-serving path patterns, with a popup-blocking script injected alongside it. Toggle from the toolbar, Settings, or the command palette.

command palette

Ctrl+K does most of it

A fuzzy-searchable list of actions: navigation, tab switching, panel shortcuts, theme switching, adblock toggle, and a go-to-or-search fallback for anything else.

icons & favicons

No external icon files

All UI chrome icons are inline SVG. Site favicons are fetched asynchronously and cached in memory, with a letter-avatar fallback when a site doesn't have one.

themes

Four presets, fully applied

Dark, Light, Red, and Blue — applied across the native UI and the new-tab page, and persisted between sessions in cysra_data.json.

performance

Four performance modes

Lowest, Low, Medium, High — trading visual effects and caching for raw speed, depending on what the machine underneath can handle.

Side panel

micro-apps, expandable

history

Searchable, revisit any entry on double-click.

downloads

Live progress on everything in flight.

password manager

Master-password protected. Uses OS-native DPAPI on Windows; falls back to a keyed XOR cipher elsewhere. A basic-security convenience, not a hardened vault.

calculator

Exactly what it sounds like.

web shortcuts

An editable list of quick links.

extensions

Loads local .py plugins that expose an AppWidget class — see below.

translate

Via deep-translator, if you install the optional dependency.

notes

Plain text, saved to cysra_notes.txt next to the app.

settings

Theme, performance mode, and the ad blocker toggle, in one place.

Requirements

  • Python 3.9+
  • PyQt5 with QtWebEngine
  • deep-translator, optional, for the Translate panel
pip install PyQt5 PyQtWebEngine

Running on Windows

  • Clone or download the repository from GitHub
  • Install the requirements above
  • Run main.py, or use build.bat to produce a standalone .exe
python main.py
