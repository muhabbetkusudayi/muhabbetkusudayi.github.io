About

I work mostly at the edge of performance — stripping out whatever doesn't need to be there so the core function is easy to see and easy to trust. That's true of a browser as much as it is of a chat UI: fewer moving parts, fewer surprises.

Day to day that's Python — PyQt5 and Flet on the desktop side, Flask on the backend — plus Node.js where a project needs to reach the operating system directly, and plain JS/HTML/CSS everywhere a framework would just add weight. Most of my AI work runs on the Groq API. I'm also studying machine learning on the side, which mostly means reading papers slower than I'd like to admit.
